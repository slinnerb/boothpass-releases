# BoothPass releases

Public release index for the BoothPass app.

- **`releases.json`** — the changelog + version index the app checks on launch.
- **Release assets** — the signed APKs (under Releases).

Install the latest APK from the [Releases page](https://github.com/slinnerb/boothpass-releases/releases/latest).
The app auto-updates from here on every launch, from any network.
